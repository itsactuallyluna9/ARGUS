# ARGUS

**Analytical Reasoning and Grounded Understanding System**

With the rest of AI generated content online, reliable fact checking is more important than ever. ARGUS uses LLMs to (mostly) automate this process.

## Development

1. Start Chroma `uv run chroma-server-wrapper.py`
2. Start Vite `cd frontend && npm run dev`
3. Start Flask `uv run flask run .`

more polish is needed!
